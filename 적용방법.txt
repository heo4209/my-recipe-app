업데이트 방법
1. ZIP 압축을 푼다.
2. GitHub > my-recipe-app > Add file > Upload files를 연다.
3. 이 압축 파일 안의 src, public 폴더와 index.html 파일을 저장소 최상단에 업로드한다.
   기존 동일 경로의 파일은 교체한다. 파일명과 경로는 유지한다.
4. Commit changes를 누른다.
5. Vercel의 자동 배포가 Ready가 될 때까지 기다린다.
6. 앱 새로고침 후 확인한다. 홈 화면 아이콘은 캐시 때문에 갱신이 늦을 수 있다.
